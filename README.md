This project downloads UK Gilt yield data and Bank of England base rate history, then generates publication-quality charts showing how the yield curve evolved during the 2022–2023 Bank of England rate-hike cycle.
The script fetches data directly from the Bank of England statistical database, caches it locally, and produces visualisations highlighting how government bond yields moved relative to the policy rate.

Features
Automatically downloads:
2-year, 5-year, 10-year, and 30-year UK Gilt yields
Bank of England base rate history
Detects BoE rate decision dates
Generates publication-quality charts using Matplotlib
Supports interactive display or file export
